03 / BOTTLENECKS & ANALYSIS

Root Cause Analysis Framework

To safely stabilize operations, we isolated the underlying drivers behind the residual tickets that still escape to the complex tier:

• Knowledge Gaps (58%): The primary bottleneck, driven by unfamiliarity with advanced system buttons or layout views inside the newly deployed tool.
• General Flow Process (27%): Intermittent edge-case alignment steps requiring custom system adjustments.
• Task Avoidance (15%): Instances where agents intentionally route tickets out to artificially balance their local speed metrics.
